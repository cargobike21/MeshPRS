# 0014: The standard is called MeshPRS

- **Status:** accepted
- **Date:** 2026-10-29
- **Answers:** OPEN-QUESTIONS Q1
- **Spec sections affected:** title, §1

## Context

The name follows D-PRS, D-STAR's position reporting into APRS; the working expansion is Mesh Position Reporting System. It is already used across the folder.

## Options

1. **MeshPRS.**
2. **A neutral working name (MCAPRS) until later.**

## Decision

Option 1. The expansion stays "Mesh Position Reporting System", although the standard covers more than positions. Decided by Alec, 2026-10-29, on the lead agent's recommendation after the Phase 3 review.

## Consequences

No document changes.
